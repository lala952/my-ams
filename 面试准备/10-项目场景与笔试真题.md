## 一、项目难点/亮点 Q&A（面试必问，照着练）

### Q1：你这个项目最大的难点是什么？你是怎么解决的？

**参考答案（结合项目真实代码）：**

> 最大的难点是**资产变动审批模块的高并发与一致性**。
>
> 这个模块要做多级审批，审批通过后要批量更新资产状态、生成变动单、记录附件，还要跨服务调用工作流引擎。
> 我遇到了三个具体问题：
> 1. **事务失效**：审批通过后更新资产状态，因为同类方法自调用 + 异常被 catch 吞掉，导致事务不生效，出现数据不一致。我通过拆 Service、统一抛 `ServiceException` 让事务正确回滚解决。
> 2. **统计接口慢**：列表页要统计草稿/审批中/已完成/已驳回 4 个状态数量，原本串行查 4 次。我改成 `CompletableFuture` + 线程池**并行查询**，耗时降到接近单次查询。
> 3. **批量更新慢**：审批通过后逐条更新改为 Guava `Lists.partition` **分段批量更新（每批 100 条）**，配合 `RetryUtils` 做失败重试，显著提升吞吐。
>
> 另外还做了**线程池隔离**（业务池 + IO 池）和 **Redis 降级**（Redis 挂了自动走 DB）来保证稳定性。

### Q2：如何保证资产变动的并发安全（防止同一资产被并发修改）？

**参考答案：**
> 用**业务状态机 + 乐观锁/版本号 + 唯一单号**三层控制：
> 1. 资产变动单有明确状态流转（草稿 → 审批中 → 完成/驳回），只有草稿才能提交审批，已审批的不能重复审批。
> 2. 更新资产时用版本号做乐观锁，`UPDATE ... WHERE version = ?`，更新失败说明被并发修改，提示用户刷新重试。
> 3. 单号用 `RedisIdWorker` 生成全局唯一，天然防重复。

### Q3：你的缓存是怎么用的？怎么保证缓存和数据库一致性？

**参考答案（结合 `CacheClient`）：**
> 我把资产、分类、字典等**读多写少**的数据缓存到 Redis。针对三类缓存问题分别处理：
> - **穿透**：空值缓存，`queryWithPassThrough` 把 DB 查不到的空值也缓存短时间。
> - **击穿**：热点数据用互斥锁 `queryWithMutex` 或逻辑过期 `queryWithLogicalExpire` 保证只有一个线程回源 DB。
> - **雪崩**：随机 TTL + Redis 降级到 DB 直查。
> 一致性用"先更新 DB 再删缓存 + 失败重试"，强一致场景可引入 Canal 监听 binlog 异步删缓存。

### Q4：单号（资产编号/变动单号）是怎么生成的？会不会重复？

**参考答案（结合 `RedisIdWorker`）：**
> 用 `RedisIdWorker` 生成：**相对时间戳左移 32 位 + Redis `increment` 按天自增序列号**。
> Redis 的 `increment` 是原子命令，天然线程安全；按天加 key 前缀（`icr:业务:yyyy:MM:dd`），序列号每天重置，避免单 key 无限增长。全局唯一且趋势递增。

### Q5：你的项目怎么实现审批流程的？

**参考答案（结合 `ruoyi-workflow` + Activiti）：**
> 集成 **Activiti 工作流引擎**，资产模块通过 `RemoteWorkflowService`（Feign 远程调用）发起流程、完成任务。
> 流程里定义了审批节点，审批通过后回调资产模块执行资产变更。资产模块这边用 Redis 缓存"拟变更资产"的临时数据，审批通过后落库。

### Q6：如果工作流服务挂了，你的资产模块会怎样？

**参考答案（结合 `ChangeFallbackFactory`）：**
> 通过 **Feign 的降级工厂 `ChangeFallbackFactory`** 做熔断降级：工作流服务不可用时，Feign 走 Fallback 返回统一错误提示，不让异常向上传播拖垮资产模块，避免服务雪崩。

### Q7：你的线程池是怎么设计的？

**参考答案（结合 `ThreadPoolConfig`）：**
> 我做**线程池隔离**：业务线程池（`bizExecutor`，处理数据库批量操作）和 IO 线程池（`ioExecutor`，处理 PDF 导出、附件保存）。
> 参数：CPU 密集型按 `CPU核数`，IO 密集型按 `CPU核数*2`，用有界队列 `LinkedBlockingQueue(500)` 防 OOM，拒绝策略用 `CallerRunsPolicy` 保证不丢任务。全部用 `ThreadPoolExecutor` 手动创建，符合阿里规范（不用 Executors）。

## 二、业务场景设计题（考察设计能力）

### 场景 1：设计一个资产折旧计算模块
**要点：**
- 折旧方法用**策略模式**：平均年限法、双倍余额递减法、工作量法，各自一个实现类，可扩展。
- 定时任务（`ruoyi-job`）按月/年批量计提折旧，用**分段批量 + 重试**。
- 折旧结果落库，生成折旧明细，可回溯。

### 场景 2：资产盘点（库存盘点）如何设计
**要点：**
- 盘点单（Inventory）+ 盘点明细（InventoryDetail）。
- 盘点差异：账面数量 vs 实际数量，生成盘盈/盘亏。
- 并发控制：盘点期间锁定资产或快照。

### 场景 3：如何实现资产导入导出（Excel）
**要点：**
- 导入：POI 解析 Excel → 校验 → 分批入库 → 返回错误行报告。
- 导出：大数据量用 EasyExcel（流式），避免 OOM。
- 异步：导出任务放 IO 线程池，避免阻塞主线程。

### 场景 4：接口防重（幂等）
**要点：** 前端生成唯一 token，提交时校验并删除；或数据库唯一索引兜底；或用 Redis `SETNX` 做幂等键。

## 三、Java 笔试题（手写代码，面试常考）

### 1. 手写单例（双重检查锁）
```java
public class Singleton {
    private static volatile Singleton instance;
    private Singleton() {}
    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) instance = new Singleton();
            }
        }
        return instance;
    }
}
```

### 2. 手写一个线程安全的懒加载单例（静态内部类）
```java
public class Singleton {
    private Singleton() {}
    private static class Holder { private static final Singleton INSTANCE = new Singleton(); }
    public static Singleton getInstance() { return Holder.INSTANCE; }
}
```

### 3. 用两个线程交替打印奇偶数（wait/notify）
```java
public class PrintOddEven {
    private int num = 1;
    private final Object lock = new Object();
    public void print() {
        synchronized (lock) {
            while (num <= 100) {
                System.out.println(Thread.currentThread().getName() + ": " + num++);
                lock.notify();
                try { if (num <= 100) lock.wait(); } catch (InterruptedException e) { e.printStackTrace(); }
            }
        }
    }
}
```

### 4. 手写 LRU 缓存（LinkedHashMap）
```java
public class LRUCache<K, V> extends LinkedHashMap<K, V> {
    private final int capacity;
    public LRUCache(int capacity) {
        super(capacity, 0.75f, true); // accessOrder=true 按访问排序
        this.capacity = capacity;
    }
    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > capacity;
    }
}
```

### 5. 反转链表
```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

### 6. 判断链表是否有环（快慢指针）
```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

### 7. 生产者消费者（阻塞队列）
```java
BlockingQueue<Integer> queue = new LinkedBlockingQueue<>(10);
// 生产者
queue.put(item);
// 消费者
Integer item = queue.take();
```

### 8. 三个线程顺序打印 ABC（Semaphore）
